# Design Prism yourself

In Figma desktop, open a design file, then Plugins → Development → Import plugin from manifest. Select this folder's `manifest.json`. Run **Prism design kit**, then **Create starter kit**.

It creates editable light/dark browser frames, tab and card components, Private network states, and a `Prism theme` variable collection. This is a layout scaffold using the browser's current tokens, ready for your own design. Existing document content is untouched. The plugin has no network access and does not upload browser data.

Edit the variables in Figma, run the plugin again and choose **Export theme**, then **Download theme JSON**. In Prism open Settings → Design studio → Import theme. Colors, row height and radius transfer directly. Layout, typography, new icons and interaction changes still need an implementation pass: share the Figma file/link or your exported specifications when ready. Do not rename the variable keys used for export.

Use the supplied Prism SVGs from `../brand/source` for your identity work. No replacement logo is generated by this kit.

The plugin source has been syntax-checked, but must still be run in your Figma account for visual validation. No live Figma document has been created remotely.
